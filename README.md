# ไปฝางกัน ♡ — คริสต์มาสของเราสองคน 2026 · แผนที่ถนนจริง

สมุดทริปภาษาไทย 24–26 ธันวาคม 2026 โทนพีช ชมพู มิ้นต์ พร้อมภาพจริงและแผนภาพเส้นทาง 17 ช่วง

## เปิดใช้งาน

แตกไฟล์ ZIP แล้วดับเบิลคลิก **index.html** ด้วย Edge หรือ Chrome เก็บ `assets`, `css`, `js` ไว้ข้าง HTML ไม่ต้องติดตั้ง Docker, Node.js หรือเปิดเซิร์ฟเวอร์ หลังอัปเดตกด **Ctrl + F5** เว็บ ภาพ ฟอนต์และแผนภาพใช้ได้ออฟไลน์ ลิงก์แหล่งข้อมูลและ Google Maps ภายนอกต้องใช้อินเทอร์เน็ต

## แผนเที่ยวและแผนภาพ

เลือกแท็บวันที่ กดรายละเอียดเพื่อดูวิธีเดินทาง ถนน จุดสังเกต สิ่งที่ต้องเตรียมและแหล่งข้อมูล ช่องระยะทาง เวลาและโน้ตที่กรอกเองแยกจากข้อมูลต้นฉบับ และระบุว่าเป็นประมาณการ

ทุกช่วงใช้แผนที่ภูมิประเทศและถนนจริงที่เก็บในเครื่อง แทนภาพภูเขา/บ้านที่วาดตกแต่ง แสดงเหมือนกันใน Timeline รายละเอียด Presentation และงานพิมพ์ ไม่มี iframe หรือการเรียก tile

A สีเขียวคือเริ่มต้น B สีชมพูคือปลายทาง เส้นสีน้ำเงินม่วงเป็นแนวถนนจากพิกัดด้วย OSRM มีครบ 8 ช่วง: เชียงใหม่–ฝางไปกลับ สถานีฝาง–ร้านฮักแกะ ที่พัก–แม่มาวไปกลับ ที่พัก–บ้านยาง บ้านยาง–Hinoki และที่พัก–น้ำพุร้อน ช่วงบ้านยางใช้พิพิธภัณฑ์โรงงานหลวงฯ เป็นจุดอ้างอิง หมุดร้านยูนนานแยกต่างหาก

อีก 9 ช่วงแสดงแผนที่พื้นที่จริงและเฉพาะหมุดที่มีข้อมูล โดยไม่วาดเส้นสมมติถึงร้านเช่าหรือร้านที่ยังไม่ได้เลือก เมื่อมีหมุดร้านจึงเติมเส้นทางได้ ปุ่มเปิดนำทางใช้พิกัดสำหรับช่วงที่มีข้อมูลแล้ว

เอาป้าย Verified/Approximate/Illustrative และยืนยัน/รอยืนยันออกจากแผนที่ หน้าทริปและสไลด์ ช่องตัวเลขที่ไม่มีข้อมูลใช้ขีด — ข้อมูลต้นฉบับยังอยู่ในโค้ดและรายละเอียดแหล่งข้อมูลที่พับไว้

ระยะและแนวถนนเป็นแบบจำลองการขับรถ ไม่ใช่แนววิ่งรถโดยสารหรือการรับรองสภาพทางมอเตอร์ไซค์ เวลาที่เผื่อยังเป็นแผน ไม่ใช้เวลารถยนต์จำลองแทนรอบรถ ผู้ใช้ดูเครดิตแผนที่ฉบับเต็มได้ที่ใต้ภาพ

ภาพสไลด์เลือกตามจุดแวะ เช่น บ้านไม้ สส โฮมสเตย์ น้ำพุร้อน บ้านยาง ฮิโนกิคอฟฟี่และรถโดยสาร ไม่ใช้ภาพอ่างแม่มาวแทนทุกสถานที่ ภาพอ่างใช้เฉพาะช่วงไปอ่างและแสดงเต็มภาพเพื่อไม่ครอปเหลือแต่น้ำ ช่วงที่ยังไม่มีภาพร้านใช้รูปต้นทางพร้อมคำกำกับ หรือการ์ดขั้นตอนแทนการอ้างรูปผิดร้าน

## งบและน้ำมัน

งบใหม่ 6,000 บาท จัดสรร **6,110 บาท** แยกค่าใช้จ่าย 5,410 บาท สำรองฉุกเฉิน 700 บาท เงินยังไม่จัดสรร −110 บาท ระบบแจ้งเกินงบตามจริง เริ่มเป็นประมาณการทั้งหมด เฉลี่ยรวมสำรอง 3,055 บาท/คน ยังมีค่าต่อรถและมัดจำที่ไม่ทราบ จึงไม่ถือว่าเป็นยอดยืนยันครบทุกค่าใช้จ่าย

แก้ยอด เพิ่ม/ลบรายการ และเลือกประมาณการหรือยืนยันแล้วได้ ระบบแยกผลรวมจากเงินสำรองอย่างชัดเจน

โหมดน้ำมันเชื่อมเฉพาะ **11 ช่วงมอเตอร์ไซค์** ตอนนี้มีระยะถนนจากแบบจำลอง 5 ช่วงรวม 88.0 กม. อีก 6 ช่วงยังไม่มีระยะ แสดงรายวันและไม่รวมรถบัส การเดินหรือช่วงต่อรถที่ไม่ทราบพาหนะ ระยะยังไม่ครบจึงคง **เงินกันไว้ 160 บาท** หนึ่งรายการ ไม่อ้างว่าเป็นยอดคำนวณครบเส้นทาง เมื่อทราบบางช่วงจะคงเงินกันไว้อย่างน้อยเท่าค่าที่คำนวณได้ เมื่อครบจึงใช้ระยะรวม ÷ กม./ลิตร × บาท/ลิตร บวกเผื่ออ้อมเริ่มต้น 15% แก้สมมติฐานได้ หรือเลือกกรอกระยะรวมเอง 35 กม./ลิตรและ 40 บาท/ลิตรเป็นสมมติฐาน ไม่ใช่ราคาน้ำมันปัจจุบัน

## นำเสนอและพิมพ์

มีปก ภาพรวม บทนำ 3 วัน และ 17 สไลด์เส้นทาง รวม **22 สไลด์** จอใหญ่แผนภาพอยู่ซ้ายประมาณ 60% ข้อมูลและภาพอยู่ขวา มือถือเรียงลงและเลื่อนได้ ใช้ปุ่มลูกศร คีย์บอร์ด หรือปัดบนมือถือ กดเต็มจอได้ กด ESC เพื่อออก

ปุ่มพิมพ์/บันทึก PDF รวมทั้ง 3 วันพร้อมแผนภาพและงบ เลือก Save as PDF ในเบราว์เซอร์ เสร็จแล้วกลับมาแสดงวันที่เลือกเดิม

## ข้อมูลเดิม

LocalStorage ผูกกับเบราว์เซอร์ โปรไฟล์และตำแหน่งไฟล์ การย้ายโฟลเดอร์อาจทำให้มองไม่เห็นข้อมูลเดิม ควรสำรองยอดสำคัญก่อนย้ายหรือล้างข้อมูลเบราว์เซอร์

รุ่นนี้อ่าน `fang-trip-budget-v1` แล้วแปลงในหน่วยความจำโดยรักษารายการที่เพิ่มเอง งบและระยะรวมเดิม การแก้ไขบันทึกที่ `fang-trip-budget-v2` โดยไม่เขียนทับ V1 ข้อมูล V2 ที่เสียไม่ถูกเขียนทับอัตโนมัติ ผู้ใช้เดิมอาจเห็นยอดต่างจากงบเริ่มต้นใหม่ตามที่เคยแก้ไว้

`fang-contacts`, `fang-checklist`, `fang-theme` ใช้ต่อ ระยะ/เวลา/โน้ตเส้นทางใช้ `fang-route-overrides-v2` การเริ่มงบใหม่ต้องกดยืนยัน รีเซ็ตเฉพาะงบ V2 ไม่ลบ V1 หรือโน้ตเส้นทาง สำรองก่อนแก้ที่ `backups/before-v2-20261015-200755.zip` โปรเจกต์ไม่มี Git repository
