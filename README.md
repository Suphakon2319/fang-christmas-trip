# ไปฝางกัน ♡ — ข้อมูลเดินทาง V4

ทริปฝาง 24–26 ธันวาคม 2026 · 2 คน · กรอบงบ 6,000 บาท ธีมสมุดทริปเดิม เปิดได้ทั้งจากไฟล์และ GitHub Pages

## เปิดเว็บ

ดับเบิลคลิก index.html ด้วย Edge/Chrome โดยเก็บ css, js, assets ไว้ข้าง HTML ไม่ต้อง Docker, npm หรือเซิร์ฟเวอร์ หากดูบนมือถือ/iPad ให้เปิดลิงก์ GitHub Pages ของโปรเจกต์ กด Ctrl+F5 หลังอัปเดต แผนที่ ฟอนต์และสื่อในเครื่องใช้ได้ออฟไลน์ ลิงก์นำทาง/แหล่งข้อมูลภายนอกต้องใช้อินเทอร์เน็ต

## ข้อมูลรุ่นนี้

- 12 จุดอ้างอิง 17 ช่วงเดินทาง ต่อจุดต้น–ปลายตามลำดับครบ
- มีแนวถนนแบบจำลอง 10 ช่วง ขาดระยะ 7 ช่วง ไม่ปักหมุด JR/โกดังขึ้นเอง
- JR Bike Rental เป็นร้านรับ–คืนรถหลักที่ต้องการใช้ เบอร์และที่อยู่จากโจทย์ยังต้องตรวจตรงสาขา ไม่มีราคา/หมุดที่พอใช้คำนวณ
- เพิ่มหมุดบ้านดินเล่าจาง และเลือกฮักแกะเป็นทางเลือกมื้อวันที่ 26 แทนชื่อร้านข้าวซอยที่ไม่ทราบหมุด
- โกดังหมูกระทะเป็นตัวเลือกมีเงื่อนไข ต้องตรวจว่าเปิดเร็วพอและกลับที่พักทัน มิฉะนั้นเลือกอาหารที่พัก
- รูปจริงที่ตรวจสิทธิ์ได้ใช้ภาพน้ำพุร้อน CC0 เดิม 1 ภาพ ภาพอื่นเก็บไว้แต่หยุดแสดงจนมีสิทธิ์ ใช้ Placeholder และลิงก์ดูต้นฉบับ ไม่อ้างภาพร้านอื่นแทน

## ใช้งาน

เลือกแท็บวันที่ กดดู A→B หรือรายละเอียดเพื่อดูวิธีไป พิกัด ที่อยู่ แหล่งข้อมูลและปุ่มโทร/นำทาง เส้นสีน้ำเงินเป็น OSRM driving model ไม่ใช่การรับรองรถบัสหรือการเข้าถึงของมอเตอร์ไซค์ ช่วงที่ไม่มีหมุดแสดงพื้นที่จริงโดยไม่วาดเส้นปลอม รอบ 09:30 ขาไปและ 13:00 ขากลับเป็นตัวเลือกตามแผน ต้องโทรขอรอบจริง

โหมดนำเสนอมี 22 สไลด์ รวม 1 สไลด์ต่อ Route ใช้ลูกศร คีย์บอร์ด ปัดบนมือถือ และ ESC เพื่อออก ปุ่มพิมพ์รวมทั้ง 3 วันและงบพร้อมบันทึก PDF ได้

## งบและน้ำมัน

ยอดเริ่มต้น 6,110 บาท = ค่าใช้จ่าย 5,410 + สำรอง 700 เกินกรอบ 110 บาท ไม่ใช่ใบเสนอราคา เลือกราคา 4 ประเภท: ยืนยันแล้ว/ราคาเก่า/ประมาณการ/ยังไม่มีราคา ทุกจำนวนในตารางเป็นยอดจัดสรร เว้นแต่ผู้ใช้ระบุยืนยันเอง ราคาไม่ทราบยังเป็น null ไม่ถือว่าฟรี และมีรายการค่าต่อรถ มัดจำและล่วงเวลาที่อยู่นอกยอดนี้

ระยะมอเตอร์ไซค์ 7/11 ช่วงรวม 98.1 กม. ยังขาด 4 ช่วง คำนวณส่วนที่ทราบที่ 35 กม./ลิตร × 40 บาท/ลิตร พร้อมอ้อม 15% ได้ 128.93 บาท แต่คงเงินกันไว้ 160 บาทหนึ่งรายการจนระยะครบ ราคาน้ำมันที่ไม่มีวันที่ระบุเป็นสมมติฐาน แก้ระยะเองในรายละเอียดหรือเลือกโหมดกรอกระยะรวมได้ ไม่รวมรถบัส/การเดิน/รถรับจ้างซ้ำ

## เก็บข้อมูลเดิม

งบใหม่ใช้ fang-trip-budget-v4 อ่านจาก V2 แล้ว V1 เมื่อไม่มี V4 ไม่เขียนทับต้นฉบับและไม่บันทึกเมื่อเพิ่งโหลด เก็บรายการเพิ่มเอง ยอดงบและสมมติฐานน้ำมันเดิม เริ่มงบใหม่ต้องกดยืนยัน รีเซ็ตเฉพาะ V4

ระยะ/เวลา/โน้ตใช้ fang-route-overrides-v4 อ่าน V2 เฉพาะช่วงที่ต้น–ปลายเดิมไม่เปลี่ยน ไม่ย้ายระยะของร้านเก่าไปใช้กับร้านใหม่ คีย์เดิมไม่ถูกลบ ส่วนธีม เช็กลิสต์และสมุดติดต่อยังใช้คีย์เดิม LocalStorage แยกตามเบราว์เซอร์และ origin ข้อมูลจาก file:// ไม่ย้ายไป GitHub Pages หรือซิงก์ข้ามเครื่องเอง

## แก้ข้อมูลกลางและอัปเดตเว็บ

แก้ JSON ใน travel_research แล้วรัน:

```powershell
node scripts/build-travel-data.mjs
node tests/verify-travel-data.mjs
```

ตัว build สร้าง js/travel-research-data.js แบบ deterministic สำหรับ file:// จึงไม่ต้อง fetch JSON ขณะเปิดเว็บ Timeline และ Presentation ใช้วัตถุเส้นทางเดียวกัน ห้ามแก้ bundle ที่สร้างแล้วโดยตรง เมื่อได้หมุดใหม่ต้องคำนวณ geometry พร้อมอัปเดตภาพ/ขอบเขตแผนที่ที่ตรงกัน ไม่ใส่แค่ตัวเลขระยะ

แก้เสร็จ commit และ push main เพื่ออัปเดต GitHub Pages ผ่านลิงก์เดิม ไม่ต้องเปิดคอมทิ้งไว้ Node ใช้เฉพาะตอนเตรียมข้อมูล ผู้เปิดเว็บไม่ต้องติดตั้ง

ทดสอบเบราว์เซอร์สำหรับผู้พัฒนา: python tests/browser_check.py ต้องมี Microsoft Edge และ Python websocket-client เครื่องมือใช้โปรไฟล์แยกใน .qa และไม่แตะข้อมูลผู้ใช้ ทดสอบพาธแบบ GitHub Pages ด้วย python tests/http_smoke.py เซิร์ฟเวอร์ทดสอบผูกเฉพาะ 127.0.0.1 และปิดเมื่อเสร็จ
