# รายงานตรวจสอบข้อมูลเดินทาง V4

ตรวจค้น 16 ตุลาคม 2026 สำหรับทริป 24–26 ธันวาคม 2026 จำนวน 2 คน กรอบงบ 6,000 บาท ไม่ได้โทรติดต่อร้าน จองบริการ หรือรับใบเสนอราคา การพบชื่อ/หมุดสถานที่ไม่รับรองบริการในวันเดินทาง

## สิ่งที่นำมารวม

ฐานข้อมูลกลาง `places/routes/transport/restaurants/accommodation/prices/photos/sources.json` อยู่ในโฟลเดอร์นี้ ใช้สถานะ official, third_party, estimated และ unconfirmed แยกความน่าเชื่อถือรายฟิลด์เมื่อมีแหล่งต่างกัน ตัวเลขที่ไม่มีหลักฐานคงเป็น null

ข้อมูลสถานที่ 12 จุด: สถานีช้างเผือก สถานีรถบัสข้างโรงพยาบาลฝาง โฮมสเตย์ จุดชมวิวแม่มาว พิพิธภัณฑ์บ้านยาง Hinoki น้ำพุร้อน ฮักแกะ บ้านดินเล่าจาง JR โกดัง และฮิโนกิคอฟฟี่ มีพิกัด 9 จุด อีก 3 จุดไม่มีหมุดเฉพาะ ได้แก่ JR โกดัง และประตูคาเฟ่ภายใน Hinoki

ร้านอาหาร: ฮักแกะใช้มื้อกลางวันวันที่ 24 และตัวเลือกวันที่ 26; บ้านดินเล่าจางใช้หมุดร้านจาก Wongnai ไม่ใช้หมุดพิพิธภัณฑ์แทน; โกดังเป็นตัวเลือกจากโจทย์ที่ต้องตรวจสอบก่อนเลือกแวะ; ฮิโนกิคอฟฟี่อ้างหน้าเจ้าของสถานที่

JR เพิ่มเป็นร้านรับและคืนรถในแผนเรียบร้อย ชื่อมีแหล่งรองประกอบ แต่เบอร์ 086-117-7576 และที่อยู่ 12/16 โชตนามาจากข้อมูลโจทย์ ยังไม่พบหลักฐานยืนยันตรงสาขา ไม่พบหมุดหน้าร้าน รุ่นรถ ราคา มัดจำ เงื่อนไขซ้อนสองและหมวก จึงไม่ได้คำนวณระยะช่วง JR หรือใช้สถานีรถบัสแทน

## งบและราคา

ไม่มีราคาใดได้รับคำยืนยันสำหรับทริปนี้ (Confirmed Price = 0 รายการ) ยอดจัดสรรใหม่ยัง 6,110 บาท: ค่าใช้จ่าย 5,410 + สำรองฉุกเฉิน 700 เกินกรอบ 110 ไม่ปรับลดค่าใช้จ่ายเพื่อบังคับให้พอดี

ราคาเก่า (Historical): ค่ารถจากข้อมูลรองที่เคยพบซึ่งขัดกัน และที่พัก 350 บาท/คน/คืนจากรีวิว 2025 ไม่ใช่ราคา ธ.ค. 2026

ประมาณการ (Estimated): อาหาร คาเฟ่ ค่าเข้าและน้ำมันเป็นเงินจัดสรร ส่วน Unknown เช่น JR มีเงินกันไว้ 600 บาทแต่ priceTHB ยัง null ไม่ใช่ใบเสนอราคาหรือราคา 0 บาท ค่าเช่าเกินรอบ รถรับจ้างเชื่อมจุดและมัดจำยังไม่ทราบและอาจต้องเตรียมเงินเพิ่ม แยกเงินมัดจำคืนได้จากค่าใช้จ่ายที่สูญไป

อาหารระบุครบ 8 มื้อตั้งแต่ก่อนออกวันที่ 24 ถึงกลางวันวันที่ 26 โดยผูกวงเงินอาหารรายวัน อาหารเช้า 25/26 ยังไม่ถือว่าได้รวมในราคาที่พักแล้ว

ระยะมอเตอร์ไซค์ที่มีข้อมูล 98.1 กม. จาก 7/11 ช่วง ยังขาด 4 ช่วง 98.1 ÷ 35 = ประมาณ 2.803 ลิตร × 40 บาท/ลิตร = 112.11 บาท เผื่ออ้อม 15% = 128.93 บาทเฉพาะส่วนที่ทราบ จึงคงเงินกันไว้ 160 บาทหนึ่งรายการ ไม่แสดงเป็นยอดทั้งทริป ราคาน้ำมันไม่มีวันที่อ้างอิงจึงระบุสมมติฐาน

## ภาพและสิทธิ์

ดาวน์โหลดภาพจริงใหม่ 0 ภาพ ตรวจภาพเดิมและใช้ภาพน้ำพุร้อนของ icon0 com ที่มี CC0 ได้ 1 ภาพ พร้อมภาพวาดต้นฉบับของโปรเจกต์ ภาพเดิมอื่นมีเครดิตแต่ไม่มีหลักฐานอนุญาตเผยแพร่ซ้ำ จึงเก็บไฟล์ไว้แต่หยุดนำมาแสดง รวมถึงพื้นหลังปก ไม่มีภาพ AI ที่อ้างว่าเป็นสถานที่จริง ร้านที่ไม่มีภาพมี Placeholder พร้อมลิงก์ดูต้นฉบับ ไม่ใช้ภาพคนละร้านแทน

## การเชื่อมเว็บและข้อมูลเดิม

เรียก `node scripts/build-travel-data.mjs` หลังแก้ JSON เพื่อสร้าง bundle สำหรับเปิด file:// และ GitHub Pages โดยไม่ fetch JSON หรือเรียก Routing API ทุกครั้ง Timeline และสไลด์อ้างวัตถุเส้นทางเดียวกัน สไลด์เก็บเพียง routeId ตัวเลขไม่ถูกแยกเก็บเป็นอีกชุด

งบใช้คีย์ fang-trip-budget-v4 อ่าน V2 หรือ V1 ตามลำดับโดยไม่เขียนทับต้นฉบับ คงรายการเพิ่มเอง ยอดและสมมติฐานน้ำมันเดิม ไม่เขียนอัตโนมัติเมื่อโหลดหน้า ระยะที่ผู้ใช้กรอกใช้คีย์ fang-route-overrides-v4 และนำของ V2 มาใช้เฉพาะช่วงที่ต้น–ปลายเชิงตรรกะเดิมไม่เปลี่ยน ข้อมูลระยะช่วงเก่ายังอยู่ในคีย์เดิม ไม่ถูกนำไปคำนวณกับร้านคนละแห่ง

## หลักฐานและข้อจำกัด

ดู sources.json สำหรับ URL และระดับหลักฐานทุกแหล่ง ใช้ HTML cache เฉพาะพัฒนา ไม่แนบการล็อกอินหรือข้อมูลผู้ใช้ ไม่ได้พบหลักฐานสิทธิ์ภาพร้านอาหารใหม่ ไม่ได้ตรวจบนโทรศัพท์จริง ไม่ได้โทรจอง ดู TEST_RESULTS.md สำหรับการทดสอบที่รันจริง และ pending_confirmation.md สำหรับงานตรวจหน้างาน
